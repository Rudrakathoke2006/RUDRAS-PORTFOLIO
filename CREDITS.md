# Open-Source Credits & License Registry

This project utilizes open-source libraries, CC0 assets, and component primitives. Below is the explicit license registry adhering to open-source attribution standards:

## 🎨 3D & Graphics Libraries
- **Three.js** — [MIT License](https://github.com/mrdoob/three.js/blob/dev/LICENSE) — WebGL 3D rendering engine.
- **@react-three/fiber & @react-three/drei** — [MIT License](https://github.com/pmndrs/react-three-fiber/blob/master/LICENSE) — Declarative 3D scene graph for React/Next.js.
- **GSAP (GreenSock Animation Platform)** — [Standard License](https://greensock.com/licensing/) — Smooth scrolltrigger timelines & text reveals.
- **@studio-freight/lenis** — [MIT License](https://github.com/studio-freight/lenis/blob/main/LICENSE) — Smooth scroll engine.

## 🔊 Audio Engine & Sound Effects
- **Web Audio Synth Engine** — Synthesized procedurally via Web Audio API (Sine/Triangle oscillators for UI clicks & section whooshes). 100% Royalty-Free, Public Domain.
- **Howler.js** — [MIT License](https://github.com/goldfire/howler.js/blob/master/LICENSE) — Opt-in audio playback context.

## 🧱 UI Component Primitives & Animations
- **React Bits** — [MIT License](https://reactbits.dev) — Text scramble effects, Aurora backgrounds, and cursor particles.
- **Aceternity UI / Magic UI** — [MIT License](https://ui.aceternity.com) — Bento Grid layouts, Spotlight card glow, and kinetic typography.
- **Geist & Bricolage Grotesque Fonts** — [SIL Open Font License 1.1](https://scripts.sil.org/OFL) — Typography system.

## 📦 3D Models & Assets
